60-Second Setup in the iOS Shortcuts App

  1. Open the Shortcuts app on your iPhone.
  2. Tap the + button in the top right to create a new shortcut. Name it "Choice AI".
  3. Add Action 1: Get Clipboard
  4. Add Action 2: Get Contents of URL:
    • URL: Paste the URL from Step 1 above.
    • Method: POST
    • Request Body: JSON
    • Add field: Key = text, Value = Clipboard
  5. Add Action 3: Copy to Clipboard (Set input to Contents of URL).
  6. Add Action 4 (Optional): Show Notification (to preview the text).
  7. Tap Done.

Enable 2-Tap Trigger (Back Tap or Action Button)

To trigger this without ever leaving Google Voice, WhatsApp, or iMessage:

How to set up Back Tap on iPhone:

Go to iPhone Settings ➔ Accessibility ➔ Touch ➔ Back Tap ➔ Choose Double Tap ➔ Scroll down to Shortcuts and select Choice AI.

If you have iPhone 15 Pro / 16 (Action Button):

Go to iPhone Settings ➔ Action Button ➔ Swipe to Shortcut ➔ Choose Choice AI.
